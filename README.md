# Danny Sousa — Beauty & Lifestyle

Landing page estática, responsiva e mobile-first para apresentação profissional da criadora de conteúdo Danny Sousa.

## Fotos pendentes

Adicione as imagens reais em `assets/` com estes nomes:

- `danny-hero.webp` — foto principal.
- `danny-01.webp` — galeria beleza/unhas.
- `danny-02.webp` — lifestyle.
- `danny-03.webp` — bastidores.

Use imagens WebP otimizadas. O layout mantém fundos de reserva até as fotos serem adicionadas.

## Projeto

HTML, CSS e JavaScript puros. Não exige instalação de dependências nem comando de build. A página deve ficar com `index.html` na raiz do repositório.
